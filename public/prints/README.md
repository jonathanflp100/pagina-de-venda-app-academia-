# Imagens do App (Mockups)

Coloque aqui os prints de tela da sua aplicação:
- `home.png` -> /prints/home.png (Tela inicial do aluno)
- `treino.png` -> /prints/treino.png (Ficha de treino interativa)
- `evolucao.png` -> /prints/evolucao.png (Gráfico de evolução e cargas)
- `checkin.png` -> /prints/checkin.png (Check-in por QR Code na recepção)
- `relatorio.png` -> /prints/relatorio.png (Relatório de alunos e frequência)
- `config.png` -> /prints/config.png (Configuração da marca, logo e cores)

Se as imagens não forem colocadas, a landing page exibe automaticamente um mockup visual realista e estilizado como fallback.
